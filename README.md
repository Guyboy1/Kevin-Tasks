# Kevin-Tasks
Kevin Tasks is a program that uses Artificial Intelligence to provide an affordable self opperating computer for personal use.

### This program was made a few years back by when agentic harnesses for computer use did not exist yet. This project was my attempt at it. It is not fully polished, as official and/or better agentic harnesses got released. I still have this project around just as a piece of history.

## Requirments: 
#### An open router api key. 
You dont need to pay. You can do up to 50 simulations of the program before your free api key reaches its limit. This program uses gpt-4o mini so it is very cheap. Get your key here: https://openrouter.ai/settings/keys
#### Python 3 or newer.
You can download python 3 using the simple command: brew install python
#### MacOS
This is a MacOS program. It does not work on windows (It may work on linux).
